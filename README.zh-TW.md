# 投稿決策台 Submission Desk

單檔、零相依的小工具,用來**可重現地**決定一份稿子該投哪本期刊。

> English README: [README.md](README.md)

期刊選擇通常憑感覺,或是照影響因子名單往下走。這個工具把它拆成每次餵同樣輸入就得到同樣答案的三步:**硬性門檻 → 計分 → 排序梯隊**,外加狀態流程與時程圖,讓「衝一本高分刊」的代價以週數呈現。

**[打開工具 →](https://YOUR-USERNAME.github.io/submission-desk/zh-TW/)**

不需編譯、不需安裝、不追蹤、不儲存。用瀏覽器打開 `zh-TW/index.html` 就能離線使用。

## 五個區塊

1. **硬性門檻** —— 主題契合、資料庫收錄、非掠奪型、APC 在預算內、接受你的文章類型。任一項不過就出局,五項全過才進入計分。
2. **候選期刊** —— 可編輯的表格:IF、接受率、契合度(1–5)、週數、APC。兩種排序模式:**期望產出**(預設)與**平衡加權**(權重可調)。
3. **排序結果** —— 同樣輸入必得同樣名次。
4. **流程與狀態** —— 八個固定狀態,含拒稿 → 下一本的迴圈。
5. **時程甘特圖** —— 可編輯;勾選即加入一次「被拒 + 改投」循環。

## 方法

```
接受機率 = clamp((接受率 ÷ 100) × 契合係數, 0.02, 0.95)
契合係數 = 0.5 / 0.75 / 1.0 / 1.3 / 1.6   對應契合度 1–5

EIM = 接受機率 × IF ÷ (週數 ÷ 4.345)
```

完整推導與參數出處:**[docs/METHOD.md](docs/METHOD.md)**(英文)。

## 用 Crossref 自動填表

五欄裡有兩欄可以不靠猜:

```bash
python3 tools/crossref_index.py --issn 1741-7015 2045-2322 \
    --mailto you@university.edu -o data/snapshots/mine-2026-07-24.json
```

再用工具裡的**匯入 Crossref 快照**讀進來。檔案由瀏覽器在本機讀取,頁面本身不連網、不儲存。

Crossref 是持續更新的資料庫,所以「即時查詢」並不可重現。**快照檔才是那個決定性的產物**:它記錄每一個請求網址、每一個釘住的參數,以及所有原始回應的 SHA-256,數字因此固定且可稽核。`--verify` 會重跑並回報漂移。

**拿得到的:**引用率(以開放引用數計算的 IF 形狀替代指標)、投稿到接受的中位數天數、接受到刊出天數、年產量、授權覆蓋率。

**拿不到的:**接受率與 APC 不在 Crossref 裡,仍需手填。契合度則是「你的稿子 × 這本期刊」的性質,不是期刊的性質,任何資料庫都不會有。

**覆蓋率門檻。**中繼資料上傳極不平均 —— Springer Nature 系列約 97–100% 的文章有審稿時程,不少學會期刊則是 0%。覆蓋率低於 30% 時工具回傳 `null` 並說明原因,而不是拿零星幾筆算中位數。用 3% 文章算出來的數字,長得跟用 97% 算出來的一模一樣;這正是最該防的失敗模式。

完整說明見 **[docs/CROSSREF.md](docs/CROSSREF.md)**(英文)。

## 證據基礎

**有實證的部分。** Rees 等人 2022 年調查 691 位通訊作者:重視契合度使首投命中的勝算比達 2.11(95% CI 1.55–2.88),重視發表速度為 1.80,而**重視影響力反而降到 0.37**(0.28–0.49),太晚決定期刊為 0.77。時程預設值同樣取自這份調查:首次決議平均 8.4 週、投稿到接受 19.6 週、平均投 1.5 本、第二本首次決議 6.7 週。

Salinas 與 Munch 2015 年在 PLOS ONE 提出的馬可夫決策模型,骨架與 `EIM` 相同,其簡化指標與完整模型的排序相關性達 ρ = 0.920。他們有推導、有資料;`EIM` 是簡化版。

**未校準的部分(介面標為 `未校準`)。** 契合係數本身、`接受率 × 契合係數` 這個乘法形式、上下界 0.02 與 0.95、平衡模式的預設權重 35/30/20/15,以及「除以月數」而非依職涯時間視野 *T* 折現。這些都是合理但未經驗證的猜測。

**證據反過來的地方。** Salinas 與 Munch 測過「照 IF 往下投」這個策略:時間視野超過 3 年時,期望引用數從未低於最佳解的 90%,主題子集合內約 70%。真正的代價在別處 —— 少拿 4 到 14 次引用可換得省下 0.5 到 1.5 次重投與 30 到 150 天。所以準確的說法是:**IF 階梯不太傷引用數,但很傷時間與首投命中率。**

**一個設計繞不開的限制。** 接受率與審查時程常常不公開;Salinas 與 Munch 聯絡 131 本期刊只拿到 61 本的可用資料,並在文末呼籲期刊公開這些數字。表格裡最難填的兩欄,難填是有結構性原因的。請當成估計值,並記下每個數字的來源。
